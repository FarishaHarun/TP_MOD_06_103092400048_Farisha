JAWABAN SOAL 1-3

1. JavaScript adalah bahasa pemrograman tingkat tinggi yang digunakan secara luas dalam pengembangan web untuk menambahkan interaktivitas pada halaman. Bahasa ini memungkinkan manipulasi langsung terhadap Document Object Model (DOM), mendukung penanganan berbagai event seperti klik atau input pengguna, serta digunakan untuk validasi form sebelum data dikirim ke server. Selain itu, JavaScript menjadi fondasi bagi banyak framework dan library modern yang memperluas fungsionalitas web.

2. jQuery merupakan library JavaScript yang dirancang untuk menyederhanakan penulisan kode dengan sintaks yang lebih ringkas. Library ini mempermudah manipulasi DOM, menyediakan fungsi animasi dan efek visual, mendukung komunikasi AJAX tanpa perlu memuat ulang halaman, serta mengatasi masalah kompatibilitas lintas browser. Dengan demikian, jQuery mempercepat proses pengembangan web melalui fungsi-fungsi siap pakai.

3. JavaScript adalah bahasa inti yang berdiri sendiri dan digunakan untuk membangun interaktivitas web secara mendetail, sedangkan jQuery merupakan library berbasis JavaScript yang berfungsi sebagai alat bantu untuk menyederhanakan penulisan kode. JavaScript memiliki sintaks yang lebih panjang dan fleksibel, sementara jQuery menawarkan metode singkat seperti .click() atau .hide() untuk manipulasi DOM. Dari segi kompatibilitas, JavaScript terkadang menimbulkan perbedaan antar browser, sedangkan jQuery menyediakan solusi agar kode lebih konsisten. JavaScript lebih cepat karena langsung berinteraksi dengan API bawaan browser, sedangkan jQuery sedikit lebih lambat akibat adanya abstraksi tambahan. Dalam konteks modern, JavaScript tetap menjadi dasar utama pengembangan web, sementara jQuery kini kurang relevan karena digantikan oleh framework yang lebih canggih.
